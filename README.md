# 📊 Amortization Calculator

A simple web-based **Amortization Calculator** built with **HTML**, **CSS**, and **JavaScript**. This tool helps users calculate monthly loan payments and generate a basic amortization schedule based on user inputs.

## 🚀 Features

- Calculate monthly loan payments
- Generate an amortization schedule
- Clean and responsive UI
- Fully client-side (no backend required)

## 🛠️ Technologies Used

- **HTML5** – Structure of the page
- **CSS3** – Styling and layout
- **JavaScript** – Business logic for amortization calculations
